# Stable V2 Strategy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an experimental stable-v2 adaptive strategy config that can explicitly choose cash in weak regimes and be evaluated against the current default.

**Architecture:** Extend adaptive strategy resolution to understand a `cash` sentinel in `regime_orders`. Create a candidate YAML config that keeps existing pullback behavior only in strong bull regimes and chooses cash in neutral/unknown regimes.

**Tech Stack:** Python 3, unittest, YAML config, existing local adaptive backtest.
