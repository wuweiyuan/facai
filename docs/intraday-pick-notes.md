# 盘中候选备忘

## 竞价候选执行纪律

`auction-pick` 应该当成早盘观察池，不应该当成强制买入信号。

难点不是选出候选股，而是 A 股普通股票是 T+1：买入后当天不能卖。开盘竞价看起来强的票，开盘后也可能快速冲高回落，一旦买进去，当天没有盘中止损退出的机会。

当前执行结论：

- 默认开盘前 5 分钟不买，只观察。
- 开盘后快速急拉的候选不追。
- 跌破开盘价或分时均价线/VWAP 的候选不买。
- 当前涨幅已经超过约 5% 的候选不买。
- 如果 09:35 后仍考虑买入，要求股价仍在开盘价和 VWAP 上方，涨幅大致在 2%-5%。
- 只允许小仓位试，比如计划仓位的三分之一。
- 如果临盘很难判断，就跳过。

实际结论：

`auction-pick` 主要用于观察早盘强势方向和市场主线。除非信号简单、干净，并且确认后仍有可执行买点，否则不应该作为主要买入策略。

`tail-pick` 更适合作为主要人工候选，因为尾盘时一天走势基本走完，强弱和回落情况更容易判断。
