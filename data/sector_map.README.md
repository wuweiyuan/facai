# sector_map.csv 说明

文件路径：

- `data/sector_map.csv`

用途：

- 给策略提供 `股票 -> 板块/行业` 的映射
- 后续做“板块强弱增强版”策略时会用到

最小格式要求：

```csv
symbol,sector
000001,银行
600519,白酒
```

字段说明：

- `symbol`
  - 6位股票代码
  - 可以不带交易所后缀
- `sector`
  - 板块或行业名称
  - 你可以按自己的体系来，比如：
    - 一级行业
    - 二级行业
    - 自定义题材

建议：

- 同一只股票只保留一条主映射
- 先保证覆盖你常见关注的股票，不要求一次性全市场齐全
- 如果后续你想做“行业”和“题材”两套映射，可以再拆成两份文件

检查方法：

```bash
python3 -m app.main check-sector-map --path data/sector_map.csv
```

你会看到：

- 总行数
- 板块数量
- 匹配到本地缓存股票的数量
- 未匹配代码数量
- 最大的几个板块

通过这个检查后，再继续做板块强弱增强版策略会更稳。
